# hello-world (REQ-0001)

最小可运行的 Python hello world 脚本。

## 环境要求

- Python 3.8+（本机实测 3.12.6）

## 运行

```bash
python hello.py
```

## 期望输出

```text
Hello, World!
```

## 测试（可选）

```bash
python -m unittest discover -s tests -v
```
